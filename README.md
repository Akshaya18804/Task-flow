# TaskFlow – Student Task Management System

TaskFlow is a **student-focused task management web application** designed to help students organize assignments, deadlines, and daily goals in one simple workspace.

The application allows users to create, manage, prioritize, search, filter, and track their tasks while monitoring their overall progress through task statistics.

## 📌 About the Project

TaskFlow was developed as a practical web application for managing academic and personal tasks efficiently.

The application provides a simple workflow where users can create an account, add tasks with categories and priorities, set due dates, mark tasks as completed, and monitor their progress.

It is designed with a responsive interface so that students can access and manage their tasks across desktop, tablet, and mobile devices.

---

## ✨ Features

### 📝 Task Management

* Add new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* Add categories and notes
* Manage tasks from a centralized workspace

### 🚦 Task Priorities

Tasks can be assigned different priority levels:

* 🔴 High
* 🟡 Medium
* 🟢 Low

This helps users focus on their most important work first.

### ⏰ Due Date Management

* Set deadlines for tasks
* Track upcoming deadlines
* Automatically identify overdue tasks
* Improve deadline management

### 🔍 Search & Filter

Users can quickly find tasks using:

* Keyword search
* Task status
* Priority
* Category

### 📊 Task Statistics

The application provides an overview of:

* Total tasks
* Completed tasks
* Pending tasks
* Overdue tasks

This helps users understand their productivity and progress.

### 👤 User Account

TaskFlow includes account-related functionality such as:

* User registration
* Login
* Logout
* Profile management
* Password update

### 📱 Responsive Design

The application is designed to work smoothly across:

* Desktop
* Tablet
* Mobile devices
